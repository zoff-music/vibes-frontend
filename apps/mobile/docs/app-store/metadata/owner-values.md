# Owner-only values required before submission

These values cannot be safely inferred or committed to a public repository.
Complete them directly in Apple Developer, App Store Connect, or EAS.

- Apple Developer team and distribution certificate
- App Store Connect app record for bundle ID `me.zoff.mobile`
- App Store Connect Apple ID (`ascAppId`) in `eas.json`
- App Review contact first name, last name, email, and telephone number
- App Store Connect API key stored in EAS credentials
- Banking/tax agreements only if the price changes from Free
- Final territory availability confirmation

Never commit API key files, private keys, signing certificates, provisioning
profiles, passwords, or App Store Connect credentials.
