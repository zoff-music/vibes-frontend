# Age rating

Answer the App Store Connect age-rating questionnaire from the app's actual
content and features, not from the intended audience.

Recommended answers for the current release:

| Question area | Suggested answer | Reason |
| --- | --- | --- |
| Parental controls | None | Zoff has no parental-control feature. |
| Age assurance | None | Zoff does not verify age. |
| Unrestricted web access | No | Users search enabled catalogues; there is no general web browser. |
| User-generated content | Yes | Users create room names, queues, and optional nicknames. |
| Messaging/chat | No | Zoff has no direct messaging or chat. |
| Advertising | None | Zoff does not display ads. |
| Gambling/loot boxes | None | Not present. |
| Sexual, violent, drug, profanity, or horror content | Infrequent/Mild | Provider-supplied music titles, artwork, lyrics, and videos can contain mature themes. |

Use Apple's calculated age rating unless App Review asks for a higher override.
Do not choose “Made for Kids.” Provider content can vary and is not curated for
children.
