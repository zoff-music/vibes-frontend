# 0.3.0 — Room chat and public rooms

## Changes

- Switch between Up next and Chat without hiding the current song.
- Live chat includes song additions, votes, admin deletions and name changes.
  Admin messages display a crown; Chat shows an unread count.
- Turn Room chat off in device settings, directly above Player enabled.
  This closes the chat connection and hides chat on this device. Room actions
  still appear to other listeners. The preference survives app restarts.
- Switch between Live rooms and All public on the home screen, search by name,
  and browse twelve rooms at a time, including rooms without listeners.

## Backend dependency

Deploy the matching `zoff-music/vibes-backend` changes before releasing this app.
Chat uses POST and SSE GET `/api/v1/rooms/{id}/messages`, independently of
playback events. Redis retains up to 1,000 events for two hours with the default
replay settings. Reconnects resume from a stream cursor. No database migration
is required.

The native version is 0.3.0 in both app.json and package.json. Build numbers remain
managed by the existing EAS configuration. No Expo publish, update or submission
was run as part of this change.

## Release verification

Workspace lint and type checks, mobile config validation, the web production
build, and local iOS/Android bundle exports pass. Local backend checks cover
message validation, author identity, separate SSE traffic, replay and expiry.
Browser checks cover unread counts, admin deletion, opt-out persistence and
activity while opted out.

Before distributing the native build, check the composer with the software
keyboard on a physical iPhone and Android device, chat opt-out/re-enable and
reconnects. Native visual verification remains outstanding because the simulator
could not be controlled while the host was locked. Review the updated App Privacy
answers and chat-related user-content declarations when preparing store metadata.
