# Store screenshots for mobile 0.4.0 and TV 0.2.0

Fresh landing and public-room browser screenshots for the September 2026 native
release. Store screenshot upload access was not available in the local session,
so these assets are ready for manual upload. This does not affect the completed
Expo binary submissions.

| Google Play, Android TV | [android-tv](android-tv/) | 1920 × 1080 |

Use the numbered order. The light iPhone landing is an optional alternative to
the dark landing. Replace the old landing screenshot and add the room-browser
image; keep existing player, search, remote, and settings screenshots since this
release only redesigned the landing and public-room browser.

The first landing screenshots in the existing
[App Store submission packet](../../../../apps/mobile/docs/app-store/README.md)
have also been refreshed. Do not upload both the old packet landing and its
duplicate from this folder.

## Capture details

- iPhone and iPad use the released 0.4.0 source in native simulator preview clients.
- Android phone and tablet use the submitted 0.4.0 production bundle, build 82.
- Android TV uses the submitted 0.2.0 production bundle, build 28.
- Android bundles are locally signed with a test key only for emulator installation.
- Screens show real public-room data, which changes over time.
- Images are unframed and unscaled opaque JPEGs, with no alpha channel.
- No private rooms, credentials, or pairing tokens are included.

Do not use the older draft screenshots as store assets. These images are the
updated release packet; they have not been uploaded to either store automatically.
